# 现代界面测试版 · 0.4.5-dev

## 新版导航

- 车辆：顶部联动连接标记、车辆图片和车牌、解锁／锁车、车型／车牌／账号身份／脱敏 VIN，以及绑定目标和 topic。
- 联动：连接状态、启用开关、绑定摘要。已绑定时收起配置，点击“修改设备绑定”展开；保存成功收起，失败保留编辑区域。
- 设置：账号会话、当前车辆 PIN、通知、后台运行设置、版本与开源许可。首页更换车辆后，PIN 设置随之切换。

页面使用圆角卡片、统一按钮和底部导航图标，颜色跟随系统浅色／深色主题。三个 Tab 在同一 Activity 内切换，底部导航保持固定，采用短暂淡入并保留各页滚动位置。车辆请求结果在车锁卡片显示，切换车辆清除旧的请求提示，不显示未经验证的实时车锁状态。

## 图片

直接使用 getAllListByUserId 返回的 diFansVehicleImg，不增加其他车辆接口。图片异步加载，切换车辆会取消旧请求；缺图或请求失败显示占位图。图片请求独立于账号接口，不发送账号 Cookie、Token 或 PIN；只使用 HTTPS，旧 HTTP 链接尝试相同地址的 HTTPS。限制下载大小和解码尺寸，不写磁盘缓存。

## 验证

49 项 JVM 测试通过；Debug、Release 构建与静态检查通过。小米 13 上已查看三类页面，实际车辆图片加载成功；未发送车辆指令。深色模式与多车辆页面尚需进一步实机体验。

已有登录、PIN、设备绑定与通知设置保留，无需重新配置。

## 0.4.1 调整

操作按钮统一缩至 48dp，解锁和锁车使用同等中性样式，不表示当前门锁状态。车辆图片区域缩至 150dp。车辆页新增数据卡片：车辆列表返回的总里程可直接显示，用户点击“刷新车辆数据”后调用中国区 vehicleRealTimeRequest；仅在无有效字段且返回 requestSerial 时等待 1.2 秒并查询一次 vehicleRealTimeResult。无唤醒、PIN 校验、车锁指令或后台轮询。

显示服务端提供的总里程、电量、纯电续航、四轮胎压、最近能耗和近 50 km 能耗，缺失和负数哨兵不显示成 0；单位未知时明确标注。保留上报时间，未返回时间时明确说明；不会把数据当作实时门锁状态。授权账号可能被服务端拒绝（例如代码 240），失败不会自动重试，也不清除以前的报告。数据按车辆隔离，仅保存在进程内，退出登录清除。

新增 8 项本地测试覆盖单位、缺失值、共享账号请求封装、拒绝后停止查询、单次结果查询与多车辆数据隔离。真实账号状态接口是否可用以及新版切换体验需实机验证。

## 0.4.2 导航修复

移除内嵌联动布局残留的重复底部导航。原先 ViewBinding 将导航事件绑定到内嵌布局的隐藏按钮，外层可见按钮未收到事件。现在只有一套共享导航。仪器测试新增导航绑定归属、点击事件及三个 Tab 切换断言；测试 APK 已编译，运行结果需实机确认。49 项 JVM 测试、Debug／Release 构建与静态检查通过。

## 0.4.3 紧凑底栏与连续切换

底部导航从 72dp 缩至 56dp，图标 20dp、文字 12sp，去掉大面积选中背景。三个页面共用固定标题栏，切换前恢复滚动位置，避免先显示错误位置再跳动；以 8dp 位移和轻微透明度变化代替整页消失重现。联动内容使用独立 ID，避免内嵌布局再出现导航／视图绑定冲突。49 项本地测试和构建检查通过；具体观感需实机体验。

## 0.4.4 隐藏不支持的车辆数据

车辆状态接口明确返回代码 1001（不支持）时隐藏整张车辆数据卡片，包括刷新入口，并按车辆在原有加密账号存储中保存结果，重开应用后仍隐藏。其他车辆不受影响。网络异常、权限拒绝 240 和空数据不标记为不支持；明确重新登录会重置探测结果。50 项本地测试、Debug／Release 构建及静态检查通过。

## 0.4.5 隐藏数据区与自适应图标

直接隐藏车辆数据卡片及刷新入口，不再根据服务器返回码决定是否显示，也不从页面发起状态刷新。车型、车牌、身份、脱敏 VIN 和车辆图片仍保留。

桌面图标改为蓝色满底的自适应图标，白色车辆与无线信号图形，兼容圆形和其他系统裁切，避免旧图标被系统加白色外框。Android 13+ 支持主题单色图标。通知栏使用独立透明底白色小图标。50 项本地测试、Debug／Release 构建与静态检查通过。
