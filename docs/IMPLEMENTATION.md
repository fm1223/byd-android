# 实施与验收

1. 协议核心：基础 AES、签名、校验码对照 Node；接下来实现 WBSK 和精确请求序列化。
2. 登录与会话：加密保存、优先复用；明确失效才进行合并的静默登录，失败停止循环。不假设固定 12 小时过期。
3. 车辆与手动门锁：单辆自动选，多辆手动选；显示基础信息及发送入口。正常提交只提示请求已发送，超时提示发送结果未确认，不自动重发。
4. PIN：按车辆配置，服务端验证成功才保存；失败保留旧值。未保存时手动操作临时输入，不启用巴法云绑定；清除后暂停绑定。
5. 巴法云：固定连接默认值，只填写接入密钥及 topic 并选择绑定车辆。on 解锁、off 锁车。绑定 VIN 不随首页选车变动。忽略保留及旧消息，串行执行，不自动重发车辆命令。
6. 后台：用户启动的前台监听、常驻通知提供暂停；连接退避重连。根据真实用途声明服务类型，不能用降低 targetSdk 或伪装服务类型绕过限制。
7. 小米 13 Android 16 实测：锁屏、待机、切网、系统杀进程、重启及强制停止，明确恢复行为。旧版本允许安装不意味着相同后台行为，另测 Android 8+ 兼容性。

第一版不接 BYD MQTT、不获取最终门锁状态、不自动补执行离线命令。

参考项目位于相邻 byd 与 byd-China，仅作为研究输入；真实缓存不复制到本仓库。采用 MIT 许可证，发布前保留第三方必要归属与来源说明。
