# 登录与会话验证

## 本地结果

17 项 JVM 测试通过。Debug 与经过 R8 优化的 Release 构建完成。连接的小米 13 已安装测试包，登录页冷启动成功；没有代用户输入凭据或调用真实登录。

## 手机测试步骤

1. 输入中国区 App 账号密码，选择车辆品牌。若 Node 使用自定义 BYD_IMEI_MD5，在高级设置填相同值；默认可留空。
2. 点击登录。应显示登录成功、车辆数量及会话建立时间。
3. 关闭应用，重新打开。应显示已复用保存的会话，建立时间保持不变。
4. 点击恢复／验证会话，验证只读列表请求。网络失败不清除缓存或自动登录，网络恢复后可再次点击。
5. 可通过强制停止再打开验证跨进程恢复；正常重启手机并解锁后再打开验证加密存储恢复。
6. 退出登录会清除本机保存的账号密码、Session 及内存 Cookie。不会调用服务器注销。

目前没有独立续期接口；明确失效码才进行一次静默重新登录。此行为已模拟测试，尚未实际等待服务器会话过期。错误码 240 的含义不确定，不自动认为过期。

请只反馈脱敏界面结果与数字错误码，不提供密码、PIN、VIN 或 Token。当前版本只验证登录及车辆列表，没有门锁操作。

用户已实机验证：登录成功并显示车辆数量；强制停止后重开可复用保存的 Session。密码默认加密保存，界面显示其保存状态，退出登录清除。手机重启和真正过期后的静默登录仍待验证。
