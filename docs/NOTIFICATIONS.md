# 通知优化（0.4.10-dev）

联动页补充关闭常驻通知的详细步骤，并新增“操作结果通知设置”入口。

隐藏常驻通知：点击“在通知栏显示后台联动”，进入系统设置，关闭“车辆设备联动”类别。部分手机需进入“通知类别”或“通知管理”。请保留 App 总通知开关和“车辆操作结果”类别开启。划掉通知只是移除当前显示，后续状态更新可能重新出现。

每次手动操作或巴法云指令结束，独立更新“车辆操作结果”通知；后台联动继续更新原常驻通知。两类互不依赖，不会主动开启被用户关闭的类别。结果通知显示服务器报告的成功、失败或结果未知，组合操作显示两行结果。查询失败不改写成车辆操作失败。正在执行时被拒绝的重复指令会提示未执行。

结果通知保留最近一次操作，支持展开查看完整文字，点击打开车辆页，点击后自动移除。自 0.5.1 起后台联动和结果通知均申请公开的锁屏可见性，新建通知类别也声明支持锁屏内容。系统和用户已保存的通知类别设置拥有最终决定权；需要在系统设置中允许锁屏通知和内容显示，不会自动重新开启已关闭的类别。不包含账号、PIN、Token 或 VIN。

修改文件：BridgeNotifications.kt、AuthController.kt、BemfaPanel.kt、activity_bemfa.xml、strings.xml、app/build.gradle.kts。

验证：本地单元测试、Debug 构建及 lintDebug；没有发送车辆命令。手机未连接，系统通知显示和点击交互尚待手机验证。
