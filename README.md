# BYD Vehicle Bridge · 车辆助手

车辆助手是一款面向中国区比亚迪车辆的 Android 应用，支持手动解锁、锁车、熄火、打开和关闭后备箱，以及通过巴法云和小爱同学控制车辆。

这是非官方开源项目，与车企无隶属关系。支持 Android 8.0 及以上版本，采用 [MIT 许可证](LICENSE)。第三方来源见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

## 使用前准备

- 一部可联网的 Android 手机。
- 能在官方 App 中查看并远程控制车辆的比亚迪账号，车主账号或授权账号均可。
- 该账号使用的六位车辆操作密码（PIN）。
- 如需设备联动：巴法云账号。
- 如需语音控制：米家 App，以及登录对应小米账号的小爱同学设备。

建议按“官方 App 验证 → 车辆助手手动操作 → 巴法云联动 → 小爱同学语音控制”的顺序配置。首次测试请在能观察车辆的位置进行。

## 1. 安装与登录

1. 安装项目发布或自行构建的 APK。同一签名的新版可以覆盖安装，卸载会清除本机配置。
2. 打开车辆助手，填写比亚迪账号和登录密码，选择车辆品牌。
3. 点击“登录并连接车辆”。只有一辆车时自动选择；有多辆车时，在“车辆”页的“切换车辆”中选择目标。
4. 检查车辆名称、车牌和脱敏 VIN，确认选中了正确的车辆。

应用默认加密保存密码与会话，再次打开时优先复用会话。会话明确失效时尝试静默登录，失败后需要手动登录。登录可能影响同一账号在官方 App 中的登录状态。

高级设置中的设备标识通常留空即可。目前只支持账号密码登录，不支持短信验证码登录。

## 2. 使用比亚迪授权账号

可为后台联动使用独立的授权账号，日常使用的车主账号保留在官方 App，减少同一账号重复登录的影响。

### 在官方 App 中授权

1. 被授权人先用自己的手机号注册并登录对应品牌的官方 App，设置登录密码。
2. 车主选择目标车辆，进入“车辆授权”或“授权管理”，按提示新建授权。不同品牌和版本的入口可能不同。
3. 填写被授权人的注册手机号，确认授权车辆、权限与有效期。需要具备云端远程控制权限；只有蓝牙或 NFC 钥匙权限不代表可以远程控制。
4. 被授权人在官方 App 中完成提示步骤，确认能看到车辆，并能执行所需的远程操作。
5. 在被授权账号的官方 App 中设置或确认六位操作 PIN，先验证它能正常使用。

授权要求可参考[王朝车辆授权协议](https://profilesys.bydauto.com.cn/byd/h5/app/car-authorize-agreement.html)和[海洋车辆授权协议](https://profilesys.bydauto.com.cn/ocean/h5/app/car-authorize-agreement.html)。

### 在车辆助手中登录

使用**被授权账号自己的手机号、登录密码和操作 PIN**，选择车辆所属品牌。应用自动识别授权身份，无需额外选择授权模式，也不需要车主账号的密码。

本项目使用者已验证授权账号可以登录、获取车辆列表，并执行解锁、锁车和熄火。具体可用功能仍取决于官方授权范围；授权到期或撤销后需重新处理。

## 3. 保存 PIN 并测试车辆操作

1. 在“车辆”页选择要操作的车辆。
2. 打开“设置 → 操作 PIN”，确认目标车辆，点击“验证并保存 PIN”。
3. 输入官方 App 中使用的六位 PIN。验证成功后才会保存，页面脱敏显示。
4. 返回车辆页，在“远程控制”中分别测试“解锁”“锁车”和需要使用的“熄火”。
5. 如需控制后备箱，点击“打开后备箱”或“关闭后备箱”。需要车辆和账号支持远程尾门控制；打开可能仅解锁或弹开，实际效果需验证。

后备箱支持手动操作，也可以单独添加巴法云设备，通过米家和小爱同学打开或关闭。请先手动验证车辆支持该功能，再配置联动。

PIN 按车辆单独保存。没有保存时，手动操作会要求临时输入；临时输入不会自动保存。**配置巴法云前必须验证并保存绑定车辆的 PIN。**

如希望锁车时同时熄火，在“设置 → 车辆控制偏好”开启“锁车时一并熄火”。此设置仅对当前车辆生效，同时适用于手动锁车和巴法云锁车指令。先熄火，再锁车，两步结果分别显示。熄火明确失败时不再发送锁车；熄火请求已发送但结果查询未知时，继续锁车并分别提示结果。

“最近一次操作”显示服务器反馈。**“结果未知”或“结果查询失败”不等于车辆操作失败**，请观察车辆确认，避免反复点击。应用不会自动重发车辆操作。按钮和操作记录不表示车辆当前的门锁状态。

## 4. 配置巴法云联动

### 创建巴法云设备

1. 打开[巴法云控制台](https://cloud.bemfa.com/)，注册并登录。
2. 在 **MQTT 设备控制台**创建主题（topic）。可分别创建 `car001`（车锁）与 `trunk001`（后备箱），方便同步为两个米家插座设备；已有 `car002` 也可继续使用，米家中会显示为灯。
3. 为设备填写便于识别的名称，例如“车辆门锁”。
4. 在控制台找到自己的**用户私钥（UID）**，留待填写到车辆助手。它不是比亚迪密码或 PIN。

### 在车辆助手中绑定

1. 打开“联动”页，点击“添加设备”；首次使用会直接显示设备配置。
2. 填写设备名称，例如“车辆门锁”或“后备箱”。
3. 选择控制功能：“车锁”或“后备箱”。页面会显示该功能的 on/off 对应动作。
4. 选择已经验证并保存 PIN 的车辆。未保存 PIN 的车辆不会出现在绑定列表中。
5. 首次填写巴法云的 32 位用户私钥，后续添加设备时留空即可沿用。所有设备共用同一个巴法云账号；修改私钥会影响全部设备。
6. 填写该设备对应的 topic，例如车锁用 car001，后备箱用 trunk001。必须与控制台一致，不要添加 /set 等后缀。
7. 点击“添加并保存设备”，然后开启页面顶部“启用后台联动”。
8. 如需另一个设备，再点“添加设备”重复以上步骤，使用独立 topic。等待标题右侧显示绿色“联动已连接”。

每条绑定有独立的名称、功能、车辆、topic 和启用开关，同一账号下 topic 不能重复。可以为同一辆车分别绑定车锁和后备箱，也可以绑定不同车辆，最多保存 20 个设备。首页选车不会改变已有绑定的控制目标。

### 管理和测试设备

- “启用后台联动”是总开关；每张设备卡片的开关决定该设备是否参与联动。全部设备停用后，总联动也会停止；重新启用设备后再开启总开关。
- 点击“编辑”修改设备名称、功能、车辆或 topic；点击“删除”仅移除 App 内绑定，不会删除巴法云或米家设备。
- 已在运行时，保存设备、修改启用状态或删除设备，会重新连接并订阅当前启用的设备。重新连接不会补执行旧消息。
- 更新前的单设备配置会自动保留为“车锁”设备，不需要重新输入私钥和 PIN。后备箱需要新增独立设备。
- 移除某辆车的 PIN 或该车不再可用时，其设备会停用，其他有效车辆的设备继续保留。恢复 PIN 后需要手动重新启用对应设备。

在巴法云设备控制页面发送以下内容：

| 设备功能 | on（打开） | off（关闭） |
| --- | --- | --- |
| 车锁 | 解锁 | 锁车；开启组合设置时先熄火再锁车 |
| 后备箱 | 打开后备箱 | 关闭后备箱 |

如通过其他工具发送消息，内容使用纯文本小写 on 或 off。所有车辆操作串行处理，忙碌时的新指令不会排队。正常使用无需安装额外调试工具。

## 5. 同步到米家与小爱同学

### 同步设备

1. 确认巴法云设备已经创建，车辆助手显示“联动已连接”。
2. 打开米家 App，登录小爱同学设备使用的小米账号。
3. 进入 **“我的 → 其他平台设备 → 添加”**，找到 **“巴法”**。部分版本入口可能显示为“连接其他平台”。
4. 使用刚才创建设备的**巴法云账号和密码**登录，完成页面提示的关联步骤。这里填写的是巴法云登录信息，不是用户私钥，也不是比亚迪账号。
5. 按页面提示同步或选择设备，回到米家首页检查是否出现“车辆门锁”和新增的“后备箱”设备。
6. 如名称不便识别，在米家中分别命名为“车辆门锁”和“后备箱”，避免与其他设备重名。

巴法云通过主题末尾数字识别同步类型：`001` 为插座、`002` 为灯、`006` 为开关。其他不受支持的后缀可能不会同步。首次使用建议 `car001`；具体规则和同步入口见[巴法云小爱同学接入教程](https://cloud.bemfa.com/docs/src/speaker_mi.html)。

这里的插座或灯图标是语音控制入口，实际执行的是车辆操作。同步设备后，先在米家中测试一次打开和关闭，再使用语音。

### 使用语音控制

设备命名为“车辆门锁”后，可尝试：

| 对小爱同学说 | 车辆操作 |
| --- | --- |
| “小爱同学，打开车辆门锁” | 解锁 |
| “小爱同学，关闭车辆门锁” | 锁车；开启组合设置时先熄火再锁车 |
| “小爱同学，打开后备箱” | 打开后备箱（需先配置独立的后备箱设备） |
| “小爱同学，关闭后备箱” | 关闭后备箱（需车辆支持） |

如果使用灯类型设备，只使用打开和关闭；亮度、颜色等操作不会用于车辆控制。小爱同学可识别的具体说法以设备实际响应为准。

**米家的开关状态和小爱同学对“是否打开”的回答，不代表车辆的实际门锁状态。** 本应用不会将真实车锁状态回传到米家。语音指令也会执行真实车辆操作，请确认设备名称和控制目标。

## 6. 后台运行设置

为了让手机锁屏后继续接收指令：

1. 在“联动”或“设置”页点击“后台运行设置”。
2. 在手机系统中允许后台自启动，并将应用的省电策略设为“不限制”或允许后台运行。
3. 小米手机可在最近任务中锁定车辆助手。不同系统的名称和入口可能不同。
4. 保持网络连接，锁屏后再测试一次联动，确认手机的后台设置生效。

连接状态固定显示在三个页面标题的右侧，滚动时始终可见，点击即可进入联动页。

正常重启并首次解锁后，应用会尝试恢复此前启用的联动。系统“强制停止”后需要手动重新打开应用。断网后会自动重连，但不会补执行离线车辆指令。

关闭“启用后台联动”或点击常驻通知的“停止”会停止接收指令，已经发送的车辆操作无法撤销。退出登录会清除本机账号、PIN 和绑定配置。

## 7. 通知显示设置

后台运行时有“车辆设备联动”常驻通知。若想隐藏它，同时保留操作结果提醒：

1. 在联动页点击“在通知栏显示后台联动”。
2. 进入系统通知设置，找到“车辆设备联动”，关闭该类别的“允许通知”。部分手机需要先进入“通知类别”或“通知管理”。
3. 保持**应用总通知开关**开启，同时保留 **“车辆操作结果”** 类别开启。
4. 返回应用，开关会同步系统实际状态。需要调整结果提醒时，点击“操作结果通知设置”。

仅划掉常驻通知，后续状态更新时可能重新出现；关闭类别才能持续隐藏。隐藏通知不会停止后台联动。

需要在锁屏查看通知时，在系统的车辆助手通知设置中开启“锁屏通知”，并在需要显示的类别中允许显示通知内容。小米手机可在“设置 → 通知与状态栏 → 通知管理 → 车辆助手”中查找对应选项，具体入口随系统版本不同。后台联动和操作结果均支持锁屏显示；已关闭的通知类别不会重新开启，锁屏是否亮屏或显示在息屏界面由系统决定。

手动操作或巴法云指令结束后，会另外发送结果通知，显示成功、失败或结果未知。通知保留最近一次操作，展开可查看完整内容，点击进入车辆页。

## 常见问题

| 问题 | 处理方法 |
| --- | --- |
| 登录失败 | 核对账号、登录密码和车辆品牌；登录密码与六位 PIN 是两回事 |
| 授权账号看不到车辆 | 检查授权手机号、权限及有效期，先确认官方 App 能看到，再刷新车辆列表 |
| PIN 验证失败 | 使用同一账号在官方 App 验证 PIN，确认后重新保存 |
| 无法保存巴法云绑定 | 先保存目标车辆 PIN，再核对私钥和 topic |
| 联动一直连接中或重连中 | 检查网络、私钥，避免其他工具与 App 同时使用同一私钥连接 |
| 米家没有同步设备 | 检查主题后缀、巴法云关联账号，返回其他平台设备页面重新同步；如重建了主题，车辆助手也要修改绑定 |
| 米家能控制，小爱不能控制 | 确认小爱使用同一小米账号、设备名称清晰且不重名，先尝试表格中的打开/关闭说法 |
| 语音有回应但车辆没动作 | 查看车辆助手连接状态及操作结果，确认设备所选功能、绑定目标和 PIN；语音回应不代表车辆执行成功 |
| 操作后结果查询失败 | 不要据此判断控制失败，也不要连续重复操作；检查车辆实际响应并记录脱敏错误码 |
| 隐藏常驻通知后没有结果提醒 | 保留应用总通知权限及“车辆操作结果”，只关闭“车辆设备联动” |
| 锁屏后不响应 | 检查自启动、省电策略和网络，重新打开应用查看连接状态 |

反馈问题请提供应用版本、手机型号、系统版本、操作步骤和脱敏错误提示。不要发送密码、PIN、完整 VIN、巴法云私钥或完整网络日志。

## 数据与账号管理

账号密码、会话、PIN 和巴法云私钥在手机本机加密保存。修改密码后可重新登录，修改 PIN 后需重新验证并保存。应用不提供配置跨设备迁移；更换手机后重新配置。

撤销比亚迪授权或关闭后台联动后，不能继续依靠原绑定控制车辆。巴法云与米家的关联需要在各自平台管理；车辆助手退出登录不会替你解除这些平台之间的关联。
