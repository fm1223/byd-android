# 车辆状态 API 验证（0.5.2-dev）

## 入口

车辆页“远程控制”区域点击“验证车辆状态 API”。仅查询状态，不发送唤醒、门锁、后备箱或其他控制命令，也不连接 BYD MQTT。无需输入 PIN。请求使用当前选中的车辆及其车主/授权身份。

先调用 /vehicleInfo/vehicle/vehicleRealTimeRequest；有 requestSerial 且未得到完整、新近的四门锁数据时，最多调用三次 /vehicleInfo/vehicle/vehicleRealTimeResult，沿用原编号。查询错误立即停止，不自动重试原请求。原有里程、胎压卡片仍隐藏。

显示四门锁值及车辆上报时间。1 为未锁，2 为锁定，0/缺失/未知值不作为锁车依据。缺少时间、上报超过两分钟或时间异常时，明确标注不能确认当前状态；即使在两分钟内，也仅称为近时报送，不能保证无延迟。

服务器拒绝提示脱敏后显示，包括可能的实名认证要求；不凭错误码推断账号必然不支持。授权身份按 identifierType=1 构造，并进入已有加密与签名。

## 本地验证

86 项单元测试通过，覆盖授权身份、只读端点、原编号传递、初始有胎压但仍查询门锁、无效/部分门锁与过期时间、实名认证错误提示及隐私脱敏、最多三次结果查询。Debug 构建与 lintDebug 通过。
